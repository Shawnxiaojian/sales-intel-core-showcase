# 安全与脱敏设计

## 仓库边界

- 仓库采用私有可见性，只向版权所有者和获授权人员开放。
- 只使用虚构公司和示例配置。
- `.env`、运行数据、日志和数据库默认被 Git 忽略。
- 不包含服务器地址、账号、密钥、令牌或真实接口地址。
- 展示代码不连接生产系统。

## 执行安全

- 默认模式为 `simulation`。
- 外部写入必须同时满足“允许执行”和“已审批”。
- 拒绝结果同样使用统一结构返回，便于审计。

## 发布前检查

每次展示版本发布前执行测试、编译检查和敏感信息扫描。生产仓库与作品展示仓库完全分离。

## 知识产权边界

- 本仓库不采用开源许可证。
- 查看权限不等于复制、修改、传播或商用授权。
- 对外演示使用仓库页面、版本记录和运行结果，不提供仓库克隆权限。
