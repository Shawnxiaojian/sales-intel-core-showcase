# Daily Follow-up Queue

每日队列把高优先级雷达机会和待确认客户自动整理成销售行动视图。销售仍只维护现有两张业务表，
不需要维护第三张任务表。

- 任务状态、负责人、日期、时间、渠道和结果持久保存。
- 支持开始、完成、改期、转派和软删除，并保留操作审计。
- 读取今日队列时幂等预生成第二天队列。
- 电话和邮件打开系统入口；企微生成待确认话术，不自动向客户发送。
- 完成跟进后生成 Excel 与 CRM 适配器回写待办，未配置 CRM 时不伪装成已回写。
- 非标项目不自行估算推动金额，金额能力继续作为客户选装模块。

公开仓库只展示机制与安全边界，不包含生产客户、联系人、电话或真实任务记录。
