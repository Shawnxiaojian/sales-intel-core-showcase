# 外部信号采集：37 家扩展演示

本模块展示如何在固定预算内，把销售情报采集从小规模试验扩展到完整有效客户池。

```mermaid
flowchart LR
    A["本地有效客户快照"] --> B["Mac 生成查询计划与预算"]
    B --> C["每企业一个合并查询"]
    C --> D["缓存与有限重试"]
    D --> E["来源注册表"]
    E --> F["企业匹配与严格过滤"]
    F --> G["需求雷达状态视图"]
```

## 展示重点

- 采集企业数与完成数
- 单企业请求上限
- 付费请求和缓存命中
- 错误及重试数量
- A/B/C/D 证据等级
- 招标、企业新闻、高管动态和财报分类
- AI 调用数量及成本控制

## 安全边界

该展示不包含真实企业清单、客户联系方式、生产信号内容、服务器地址、访问凭据或内部运行快照。示例数字经过虚构或概括，仅用于展示产品流程。
