# 现场展示指南

## 展示前

1. 在浏览器中登录 GitHub 账号 `Shawnxiaojian`。
2. 打开本私有仓库首页，确认页面顶部显示 `Private`。
3. 提前打开 `README`、`Insights`、`Actions` 和 `Releases` 页面。
4. 使用浏览器访客窗口确认未登录状态无法访问仓库。

## 推荐的五分钟展示顺序

### 1. 项目目标（约 30 秒）

从 README 的流程图开始，说明系统将标准化任务依次交给权限、评分、路由、执行和结果模块。

### 2. 版本演进（约 60 秒）

打开 Releases：

- `v1.0.0` 展示最小单体原型；
- `v2.0.0` 展示模块化核心；
- 结合版本演进文档说明 V3 的可观测性和审批规划。

### 3. 工程结构（约 90 秒）

依次浏览 `contracts.py`、`scoring.py`、`safety.py` 和 `orchestration.py`，重点说明职责拆分、稳定契约及默认安全策略。

### 4. 质量保障（约 60 秒）

打开 Actions 页面展示自动化检查成功记录，再打开测试文件说明评分、低分观察、权限拦截和异常输入四类行为。

### 5. 安全边界（约 60 秒）

打开安全设计与版权文件，说明：

- 展示数据全部虚构；
- 生产凭据和客户数据不会进入作品仓库；
- 生产仓库、展示仓库和服务器运行环境彼此隔离；
- 当前仓库私有，不提供复制或商业使用授权。

## 展示注意事项

- 现场只共享屏幕，不邀请陌生账号成为仓库协作者。
- 不展示生产仓库的环境变量、日志、服务器终端或部署密钥。
- 不现场下载 ZIP、克隆仓库或发送源代码文件。
- 展示结束后退出公共设备上的 GitHub 登录状态。
